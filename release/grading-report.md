## Machine evidence

### Kernel handoff (20%)

The ISOLINUX boot line hands the kernel `rdinit=/usr/bin/agent-init`, so the kernel execs agent-init from the
initramfs as PID 1. agent-init execs `/stage1` (a busybox script) to mount the CD, the SquashFS base and the
OverlayFS root, which `switch_root`s back into `/usr/bin/agent-init` on the real root, still as PID 1. `/proc/cmdline`:

```
BOOT_IMAGE=/boot/vmlinuz rdinit=/usr/bin/agent-init console=ttyS0 quiet loglevel=0 panic=0 initrd=/boot/initramfs
```
