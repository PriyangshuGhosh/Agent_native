Verification & Evaluation Harness

Deterministic, machine-verifiable test assertions across all system layers.

Boot Verification

  • Assert /proc/cmdline contains init=/usr/bin/agent-init.
  • Assert ps -p 1 -o comm= returns agent-init.
  • Assert no desktop managers (GDM, LightDM, systemd) exist in process tree.
  • Assert mounts: /proc, /sys, /dev, /run, /tmp are mounted correctly.

3-Tier Capability Assertions

  • Tier 1 Test: Load shared library into RAM via FFI, execute compute function, assert result.
  • Tier 2 Test: Launch headless Chromium, connect over CDP WebSocket, execute DOM query, assert response.
  • Tier 3 Test: Launch GUI app on HEADLESS-1, query AT-SPI tree over D-Bus, invoke action, assert state change.
