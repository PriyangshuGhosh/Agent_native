Strict isolation between deterministic low-level OS infrastructure and the higher-level cognitive agent runtime.

Deterministic Boot Flow

Bootloader (GRUB / Syslinux) ↓ Linux Kernel (init=/usr/bin/agent-init) ↓ agent-init mounts /proc, /sys, /dev, /dev/pts, /run, /tmp ↓ agent-init initializes KMS/DRM & /dev/uinput ↓ agent-init launches dbus-daemon --session ↓ agent-init launches Wayland compositor (cage -d on HEADLESS-1) ↓ agent-init spawns Agent Runtime Daemon

PID 1 Constraints

  • Written strictly in POSIX C.
  • Mounts essential kernel filesystems and handles device nodes.
  • Implements non-blocking waitpid() loop to reap orphaned child processes.
  • Supervises child processes with automatic restart upon unexpected termination.
  • No LLM/VLM code, network calls, or non-deterministic inference runs inside PID 1.

Storage Architecture

ReadOnly Base System (SquashFS) + Writable Persistent Storage (/data) + Writable Ephemeral Scratchpad (tmpfs) ↓ OverlayFS Root Abstraction
