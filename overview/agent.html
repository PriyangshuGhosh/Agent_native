Agent Architecture & Execution Logic

Deterministic on-metal execution paired with offloaded cloud reasoning, optimized for 8 GB RAM host environments.

Design Axiom: The operating system kernel and local daemon (agentd) remain deterministic, fast, and free of neural weights. Probabilistic reasoning, planning, and vision models execute in the cloud, streaming structured JSON-RPC directives to the local runtime.

Wire Protocol & Execution Cycle

1. Harvest AT-SPI JSON→ 2. Transmit Δ to Cloud→ 3. Ingest JSON Directive→ 4. Validate Bounds→ 5. Dispatch to Tier→ 6. Verify Postcondition

3-Tier Local Dispatcher Mechanics

Tier 1 • In-Memory FFI / WASI

Executes direct dynamic library calls (dlopen/dlsym) and WebAssembly Component modules inside shared host memory. Zero IPC, sub-millisecond execution.

Tier 2 • Headless Sockets & CLI

Drives native background engines via Chrome DevTools Protocol (CDP) WebSockets, Unix domain sockets, and stdio streams at raw native silicon throughput.

Tier 3 • Off-Screen Wayland (AT-SPI)

Routes GUI applications to virtual display output HEADLESS-1. Interrogates widgets over D-Bus; injects synthetic input via /dev/uinput.

Future On-Device Migration Path

The architecture allows upgrading from cloud-tethered reasoning to 100% air-gapped on-device execution without modifying the underlying operating system. The HTTP client inside agentd redirects to a local Unix domain socket (/run/inference.sock) hosting a quantized 3B–7B parameter small language model running on the host CPU or integrated GPU via Vulkan.
