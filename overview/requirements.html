System Requirements Matrix

Consolidated, non-redundant engineering requirements from kernel handoff to final evaluation.

  1. Configure minimal Linux kernel with DRM/KMS, uinput, and OverlayFS support.
  2. Implement custom PID 1 binary (agent-init) in POSIX C.
  3. Mount essential virtual filesystems (/proc, /sys, /dev, /dev/pts, /run, /tmp).
  4. Implement non-blocking child process reaping and signal handling in PID 1.
  5. Initialize session D-Bus daemon automatically during early boot.
  6. Deploy lightweight Wayland compositor with headless backend support.
  7. Allocate headless virtual display buffer (HEADLESS-1) in VRAM/RAM.
  8. Implement framebuffer extraction via wlr-screencopy protocol (≥10 FPS).
  9. Implement AT-SPI2 D-Bus client for hierarchical UI widget extraction.
  10. Implement direct AT-SPI action invocation (DoAction, SetTextContents).
  11. Implement /dev/uinput virtual mouse and keyboard event injector.
  12. Build coordinate normalization layer mapping screen space to input space.
  13. Implement Tier 1 in-memory library linking via FFI and WebAssembly runner.
  14. Implement Tier 2 headless IPC bridge for CDP WebSockets, stdio, and Unix sockets.
  15. Implement Tier 3 off-screen virtual window manager and focus controller.
  16. Build capability router mapping natural-language intents to execution tiers.
  17. Implement pre-action validation verifying preconditions before invocation.
  18. Implement post-action state verifier confirming task completion.
  19. Implement failure recovery engine triggering replanning upon anomaly detection.
  20. Design immutable SquashFS base filesystem image.
  21. Configure OverlayFS with persistent writable storage for dynamic state.
  22. Integrate autonomous package manager supporting AppImages, binaries, and libraries.
  23. Implement application registry maintaining structured capability manifests.
  24. Deploy system watchdog detecting process hangs and deadlocks.
  25. Implement user emergency stop interrupt handler.
  26. Construct automated headless QEMU testing harness.
  27. Build automated hybrid bootable ISO generation pipeline.
  28. Verify bare-metal hardware compatibility and DRM display binding.
  29. Implement structured serial telemetry logging for grading verification.
  30. Achieve 100% automated pass rate across rubric evaluation matrix.
