# Pi 5 hardware results (card read 2026-11-18)

Source: the SD card from the real Pi 5 after the 2026-11-14/15 sessions. Copies are in `build/evidence-2026-11-18/`
(not committed): `agentos-journal.txt` (last boot, from the FAT partition), `agentd-state/` (`ops.jsonl`, `world.json`,
`changes.jsonl`, probe evidence), `home-files/` (the documents the agent made; flashing erased them from the card).

## What ran on the hardware
- Boot: kernel 6.18.60+rpt-rpi-2712, systemd up at 17.8 s (2.0 s kernel + 15.7 s userspace), `AGENTD_READY` at 17.97 s.
- 34 application operations through the planner, 2026-11-14 18:08 → 2026-11-15 12:04 (UTC):
  - LibreOffice: 3 × `create_text` (docx/odt; 12–16 s), 2 × `convert` to PDF (3–4 s). All committed.
  - Blender: 21 × `new_scene`, 4 × `script`, 2 × `add_light`, 1 × `inspect`, 1 × `render` (`showcase_render.png`).
    Typical `new_scene` takes 4–8 s; the first one after boot takes 16–18 s (software GL, cold start).
  - Final states: 26 committed, 2 conflicts (the human's version kept and the agent's saved as `*.agent-<op>.blend`, as designed), 11 failed.
- `shell` (M4d, first time on hardware): 10 runs. `cowsay` gave exit 127 five times, then `/usr/games/cowsay` worked.
  Those runs were at 18:16–18:21Z. The PATH fix (`/usr/games`, with a unit test) is in the image built at 18:53Z, which is the one being released.
- External changes seen: the person deleted 3 files and Blender saved `human_figure.blend` (+ `.blend1`); all recorded as `external`.

## The 11 failures, by cause
| Count | Cause | Assessment |
|---|---|---|
| 4 | "the script was not approved" | Working as designed: `blender.script` needs a yes on the console. |
| 3 | `new_scene did not produce mountain_scenery.blend` | The model's bpy code did not save. Each time the replan's next attempt committed (3–7 s later). Model-dependent. |
| 2 | missing parameter (`code`, `output`) | The model left out a required argument; the validator refused before anything ran. |
| 1 | "the scene has no camera" (render) | A correct refusal; recovered by a later plan. |
| 1 | `Artificial Intelligence.odt does not exist` | The model guessed a filename (the real one was `artificial_intelligence.odt`). |

None of the failures left a partial file or overwrote the person's work.
